
# Maybahay
Maybahay is an ongoing website project for Animal Adoption center built with React and TailwindCSS for the author's portfolio.
Any assets used are intended for personal use only.

### Tech Stack
- **Framework:** React 19
- **Build Tool:** Vite
- **Styling:** Tailwind CSS v4, Tailwind Merge
- **Icons:** Lucide-React
- **Fonts:** Rubik (Google Fonts)

---

### Installation and Setup
1. **Clone the repo:**<br/>
      `git clone https://github.com/liiwmi/maybahay.git`<br/> 
2. **Install dependencies:**<br/> 
      `npm install`<br/> 
3. **Install styling utilities:** <br/> 
      `npm install -D tailwindcss postcss autoprefixer`  <br/> 
      `npm install tailwind-merge`<br/> 
4. **Start development server:** <br/> 
      `npm run dev`<br/>
