
# Maybahay
Maybahay is an ongoing website project for Animal Adoption center built with React and TailwindCSS for the author's portfolio.
Any assets used are intended for personal use only.

## Tech Stack:
Framework: React 19
Build Tool: Vite 
Styling: Tailwind CSS v4
Icons: Lucide-React
Fonts: Rubik (Google Fonts)

## Installation and setup
1. Clone the repo:
      git clone https://github.com/liiwmi/maybahay.git
2. Install dependencies:
      npm install
3. Start development server:
      npm run dev

# Maybahay website
A front-end (soon to be fullstack) website for an animal adoption center with the use of React and Tailwind CSS.
Any assets used in the production are intended for personal use only.

## Tech Stack
React 
Vite	
Tailwind CSS 
Google Fonts

## Installation and setup
1. Clone the repository
   - git clone https://github.com/liiwmi/maybahay.git
2. Navigate into the folder
   - cd maybahay
3. Install dependencies
   - npm install
4. Start development server
   - npm run dev
5. Build for production
   - npm run build
